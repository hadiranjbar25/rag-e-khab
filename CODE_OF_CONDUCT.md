# Code of Conduct

## Our Pledge

We pledge to make participation in this project a respectful, harassment-free experience for everyone.

## Expected Behavior

- Be kind, patient, and constructive.
- Assume good intent, especially when discussing bugs or design tradeoffs.
- Keep feedback focused on the work, not the person.
- Respect privacy and do not share private data, credentials, production data, or PII in issues, logs, examples, prompts, or debug sessions.

## Unacceptable Behavior

- Harassment, insults, threats, or discriminatory language.
- Publishing private information without explicit permission.
- Sharing raw production data, secrets, or personally identifiable information.
- Repeated disruptive behavior after being asked to stop.

## Reporting

If you see a problem, contact the project maintainer privately. Reports should include the relevant context and any links or screenshots that help explain the issue.

## Enforcement

Maintainers may remove content, reject contributions, or restrict participation when behavior violates this Code of Conduct.

## Attribution

This Code of Conduct is adapted from common open-source community guidelines and tailored for a local/private developer tooling project.
